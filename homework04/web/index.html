从一个想法到一篇文章。在这里注册、登录、管理文章与评论，也能直接查看每次 HTTP 请求的结果。

● 尚未登录10 个业务接口
先注册或登录，再开始管理文章。登录状态仅保存在当前页面，刷新后需重新登录。

01 / 用户账户

已有账户可直接登录。注册成功后仍需点击登录。

02 / 文章编辑器

发布归属于当前登录用户。填入文章 ID 可读取、更新或删除已有文章。

03 / 评论

按文章 ID 查看评论。发表、删除后自动刷新评论和我的文章；仅能删除自己发表的评论。

评论列表

登录后点击“刷新列表”查看文章。

接口清单与约定

除注册、登录外均需要 Authorization 请求头，值直接使用 JWT，不加 Bearer。页面自动完成。详情、更新、删除文章需要是文章作者。

方法路径 / 用途
GET/api/v1/comments?postId=1 · 指定文章的评论列表
POST/api/v1/users/register · username, email, password
POST/api/v1/users/login · username, password
GET/api/v1/posts · 我的文章列表
POST/api/v1/posts · title, content
GET/api/v1/posts/:id · 详情
PUT/api/v1/posts/:id · title, content（完整替换）
DELETE/api/v1/posts/:id · 删除文章
POST/api/v1/comments · postId, content
DELETE/api/v1/comments/:id · 删除评论
